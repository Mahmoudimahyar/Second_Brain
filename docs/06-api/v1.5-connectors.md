# V1.5 connector API reference

> Generated for V1.5a — the external-database connector kit. Each of
> the seven connector tools is exposed via three surfaces:
>
> 1. **MCP** — wired on the `secbrain-v1` server (Tier 1 per ADR-011).
> 2. **FastAPI** — `/api/v1/sources/*` for the Next.js UI (V1.5b).
> 3. **CLI** — `secbrain sources <verb>` (where applicable).
>
> This doc is the human-readable contract; the authoritative JSON
> schemas live in
> [`src/retrieval/connector_tools.py::connector_tool_definitions()`](../../src/retrieval/connector_tools.py).
>
> Status: closes gap-audit **MED-3** (W2-7 deliverable).

## Common error envelope

All seven tools return a `StructuredError` on failure, serialized as:

```json
{
  "error_code": "L1_IMMUTABLE_REJECT",
  "message": "L1 tier requires confirm_l1_immutable=True (source_id=...)",
  "context": {"source_id": "src:postgres:prod", "attempted_tier": "L1"}
}
```

The full error-code catalog: [`docs/06-api/error-codes.md`](error-codes.md).

V1.5b's FastAPI surface maps these to HTTP status codes per
`src/web/app.py::_status_for` — `L1_IMMUTABLE_REJECT` → 409,
`CONNECTOR_NOT_FOUND` → 404, `VALIDATION_FAILED` → 400, otherwise 500.

## 1. `connect_data_source`

Register a new external data source. The default tier is **L2**
per ADR-014; **L1** requires explicit `confirm_l1_immutable=true`
(see ADR-014's L1-immutability guard).

**Engines supported (V1.5a):** `postgres`, `mysql`, `sqlite`, `neo4j`,
`local_file`.

### Request

```json
{
  "engine": "postgres",
  "display_name": "Prod customer-of-record DB",
  "config": {
    "host": "db.internal",
    "port": 5432,
    "database": "customers",
    "schema_filter": ["public", "billing"],
    "ssl_mode": "require"
  },
  "tier": "L2",
  "confirm_l1_immutable": false,
  "credential_ref": "PROD_DB_PASSWORD",
  "actor": "operator"
}
```

| Field | Type | Default | Notes |
|---|---|---|---|
| `engine` | enum | — | One of the 5 supported engines. |
| `display_name` | string | — | Operator-facing label. |
| `config` | object | — | Engine-specific. See `src/ingestion/sources/{postgres,mysql,sqlite,neo4j,local_file}.py::*Config`. |
| `tier` | enum | `L2` | `L1` requires `confirm_l1_immutable=true`. |
| `confirm_l1_immutable` | bool | `false` | Per ADR-014. |
| `credential_ref` | string | — | Env-var name (V1.5 plaintext; V2 keychain). |
| `source_id` | string | auto | Idempotency key. |
| `actor` | string | `system` | Audit-log actor. |

### Response

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "engine": "postgres",
  "tier": "L2",
  "status": "connected",
  "label": "Prod customer-of-record DB",
  "connected_at": "2026-05-25T10:14:00Z",
  "last_pull_at": null
}
```

### Errors

| code | HTTP | Trigger |
|---|---|---|
| `L1_IMMUTABLE_REJECT` | 409 | `tier=L1` without `confirm_l1_immutable=true`. |
| `CONNECTOR_ALREADY_REGISTERED` | 409 | Idempotency mismatch on existing `source_id`. |
| `ENGINE_UNSUPPORTED` | 400 | Engine outside the V1.5a allow-list. |
| `CRED_NOT_FOUND` | 400 | `credential_ref` env-var not set. |
| `VALIDATION_FAILED` | 400 | Config missing required keys. |

### MCP / FastAPI / CLI surfaces

- **MCP:** `mcp.tool.call("secbrain-v1", "connect_data_source", {...})`
- **FastAPI:** `POST /api/v1/sources` (body = same JSON shape).
- **CLI:** `secbrain sources connect postgres --display-name '...' --config '...'`.

## 2. `discover_schema`

Walk a registered source and snapshot its schema (tables + columns +
nullability + sample values for SQL engines; labels + relationship
types for Neo4j).

### Request

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "refresh": false
}
```

### Response

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "discovered_schema": {
    "tables": [
      {
        "name": "schools",
        "columns": [
          {"name": "id", "type": "integer", "nullable": false, "sample": [1, 2]},
          {"name": "name", "type": "text", "nullable": false, "sample": ["NYU"]}
        ],
        "row_count_estimate": 65
      }
    ]
  }
}
```

### Errors

| code | HTTP | Trigger |
|---|---|---|
| `CONNECTOR_NOT_FOUND` | 404 | `source_id` unknown. |
| `SCHEMA_TOO_LARGE` | 400 | Schema exceeds NFR-1.5a-2 (200-table cap). |

## 3. `suggest_mapping`

Run `MappingSuggester` over the latest schema snapshot. Returns
per-table verdicts (`node` / `edge` / `skip`) with confidence + a
reasoning chain. **No LLM call** — purely BGE-small + rapidfuzz +
node-property dictionary per ADR-015.

### Request

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3"
}
```

### Response

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "proposals": [
    {
      "table_or_column": "schools",
      "verdict": "node",
      "target_node_or_property": "School",
      "confidence": 0.93,
      "reasoning": ["embedding match: 0.92", "column 'name' matches School.name"]
    }
  ]
}
```

Mapping gate: 50-pair F1 ≥ 0.85 (V1.5a achieved 0.900).

## 4. `commit_mapping`

Persist operator-edited mapping decisions for a source. Returns a
receipt with `decisions_committed` + `pending_hitl` counts.

### Request

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "decisions": [
    {
      "table_or_column": "schools",
      "target_node_or_property": "School",
      "confidence": 0.93,
      "decision": "accept"
    },
    {
      "table_or_column": "memberships",
      "target_node_or_property": "School",
      "confidence": 0.68,
      "decision": "edit",
      "edited_target": "Specialty"
    }
  ],
  "dry_run": false
}
```

### Response

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "decisions_committed": 8,
  "decisions_rejected": 2,
  "pending_hitl": 1
}
```

### Errors

| code | HTTP | Trigger |
|---|---|---|
| `INVALID_MAPPING` | 400 | Decision references unknown table or property. |
| `MAPPING_NOT_COMMITTED` | 400 | Schema snapshot expired between discover + commit. |

## 5. `pull_delta`

Pull rows added/changed since the persisted cursor, or force a full
resync. Returns a `PullReceipt` with row + node + edge counts. Per
NFR-1.5a-1 (Postgres 100K-row table p95 < 90s) when wired against
real testcontainers (gated on `Q-027`).

### Request

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "mode": "delta"
}
```

### Response

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "mode": "delta",
  "rows_added": 412,
  "rows_updated": 7,
  "rows_deleted": 0,
  "nodes_upserted": 412,
  "edges_upserted": 838,
  "cursor_advanced_to": "2026-05-25T10:00:00Z"
}
```

      "last_pull_at": "2026-05-25T11:00:00Z"

## 7. `disconnect_data_source`

Soft-disconnect (default) by closing the bitemporal `t_ingest_to` —
the materialized graph stays for read-only audit. `retain_graph=false`
would tombstone the materialized edges; this is a destructive operation
gated behind explicit operator action.

### Request

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "retain_graph": true,
  "actor": "operator"
}
```

### Response

```json
{
  "source_id": "src:postgres:db_internal:customers:a8f3",
  "status": "disconnected",
  "disconnected_at": "2026-05-25T11:30:00Z",
  "edges_tombstoned": 0
}
```

### Errors

| code | HTTP | Trigger |
|---|---|---|
| `CONNECTOR_NOT_FOUND` | 404 | `source_id` unknown. |

## Audit log entries

Every successful + every rejected attempt writes one row to the
`connector_audit` SQLite table (per ADR-014 §6). Kinds:

- `connector_connect`
- `connector_disconnect`
- `connector_tier_upgrade_attempt` — written for every `L1`-tier
  attempt (success + failure).
- `pull_delta`
- Plus the W2-4 `ui_*` kinds (every `/api/v1/sources/*` request).

Inspect with:

```bash
secbrain audit list --kind connector_tier_upgrade_attempt
```

or via FastAPI:

```
GET /api/v1/audit?kind=connector_tier_upgrade_attempt
```
