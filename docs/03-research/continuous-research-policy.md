# Continuous Research Policy

The agent must research current best practices before every major decision.

## Research required for

- architecture
- tech stack
- UI/UX patterns
- design system
- auth/security
- database design
- testing strategy
- GraphRAG/MCP
- agent workflow
- deployment
- AI/LLM systems
- major libraries
- open-source architecture patterns

## Research output

Each research task must produce:
- research question
- sources reviewed
- options compared
- recommendation
- tradeoffs
- risks
- user decision needed, if any
- docs updated
- ADR created, if needed

## Rule
Research must feed a decision. Do not collect links without converting them into architecture, docs, tests, or implementation rules.
