# Project Mode Examples

## Quick script
Mode: automation_script

Required:
- workflow description
- inputs/outputs
- env/config
- tests
- runbook

Skip:
- marketing
- pricing
- competitors
- full UI design system

## CLI for developers
Mode: cli_tool or developer_tool

Required:
- command reference
- examples
- install docs
- error handling
- tests
- release/versioning

Skip:
- website UI-flow unless docs site needed
- marketing unless public launch

## SaaS app
Mode: product_business

Required:
- PRD
- personas
- UI flows
- architecture
- testing
- design system
- marketing optional/required depending user preference

## AI research prototype
Mode: research_prototype or ai_agent_system

Required:
- research question
- methodology
- evaluation
- reproducibility
- data docs
- agent/tool safety if applicable

Skip:
- pricing
- sales
- campaign assets
