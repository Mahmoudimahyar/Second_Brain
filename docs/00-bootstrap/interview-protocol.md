# Interview Protocol

The goal is to understand what we are building before implementation.

## Rules

- Ask focused questions in rounds.
- Ask no more than 7 questions per round.
- Convert each answer into structured documentation.
- Track assumptions separately from confirmed facts.
- Track unresolved questions.
- Research current best practices before finalizing architecture, security, stack, testing, deployment, or AI decisions.
- Do not start coding until the relevant feature packet is complete.

## After each round, produce

- Confirmed facts
- Assumptions
- Open questions
- Docs updated
- Next recommended questions
