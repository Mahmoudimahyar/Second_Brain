# Skill: Visual Companion / UI Exploration

## Trigger
Use before implementing major UI, landing pages, dashboards, onboarding, or visual components.

## Goal
Explore visual direction before coding.

## Process
1. Read brand-system.md and design-system.md.
2. Identify page goal and user emotion.
3. Sketch layout options in text or HTML prototype.
4. Define reusable components.
5. Define states: loading, empty, error, success.
6. Check against anti-AI-slop criteria.
7. Update UI docs before implementation.

## Rule
Do not build final UI until the design direction and component reuse plan are clear.
