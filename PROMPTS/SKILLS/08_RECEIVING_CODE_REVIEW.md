# Skill: Receiving Code Review

## Trigger
Use when user/reviewer gives feedback.

## Process
1. Read feedback carefully.
2. Classify each item:
   - must fix
   - should fix
   - question
   - disagreement
   - needs clarification
3. Verify technical correctness.
4. Do not blindly accept wrong feedback.
5. Implement fixes with tests.
6. Explain any disagreement with evidence.
