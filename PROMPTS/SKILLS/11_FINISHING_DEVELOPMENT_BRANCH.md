# Skill: Finishing Development Branch

## Trigger
Use when implementation is complete and tests pass.

## Process
1. Run verification-before-completion.
2. Review changed files.
3. Ensure docs updated.
4. Ensure no unrelated changes.
5. Summarize commits/changes.
6. Offer options:
   - merge
   - create PR
   - leave branch for review
   - clean up worktree
7. Do not merge without user approval if configured.
