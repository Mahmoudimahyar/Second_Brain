# Skill: Requesting Code Review

## Trigger
Use after completing a major chunk or before merge/PR.

## Review checklist
- correctness
- tests
- edge cases
- security
- performance
- readability
- docs consistency
- module boundaries
- dependency changes
- UI consistency if relevant
- no unrelated refactors

## Output
Create a review request with:
- summary
- changed files
- tests run
- known risks
- what reviewer should focus on
