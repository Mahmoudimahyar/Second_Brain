# Skill: Executing Plans

## Trigger
Use when a written implementation plan exists.

## Process
1. Read the plan.
2. Confirm gates pass.
3. Create/update task brief.
4. Execute one small task at a time.
5. Run relevant tests after each logical chunk.
6. Update progress.
7. Stop if assumptions become invalid.
8. Produce validation report.

## Rule
Do not skip plan steps silently. If a step is unnecessary, document why.
