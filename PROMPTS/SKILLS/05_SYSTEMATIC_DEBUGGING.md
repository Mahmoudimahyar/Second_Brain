# Skill: Systematic Debugging

## Trigger
Use for bugs, failing tests, unexpected behavior, crashes, console errors, broken UI flows, or flaky behavior.

## Process
1. Reproduce the issue.
2. Capture exact error/log/output.
3. Identify expected vs actual behavior.
4. Isolate likely layer: UI, API, data, auth, config, dependency, environment.
5. Form hypotheses.
6. Test one hypothesis at a time.
7. Apply minimal fix.
8. Verify with targeted test.
9. Add regression test.
10. Update known-issues.md if relevant.

## Rule
Do not guess-fix. Evidence first.
