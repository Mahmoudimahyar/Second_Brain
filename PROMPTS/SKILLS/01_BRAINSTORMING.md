# Skill: Brainstorming / Spec Refinement

## Trigger
Use before creative work, product design, new features, UI design, architecture direction, or behavior changes.

## Goal
Understand the user's intent and refine the idea before implementation.

## Process
1. Restate the user's goal.
2. Identify project mode.
3. Identify known facts.
4. Identify assumptions.
5. Identify unknowns.
6. Ask focused questions if needed.
7. Offer decision menus when choices are ambiguous.
8. Produce a refined spec or update docs.

## Rules
- Do not code.
- Do not over-ask; no more than 7 questions per round.
- If the user dumped documents, extract facts first.
- Track assumptions in docs/00-bootstrap/assumptions.md.
- Track open questions in docs/00-bootstrap/unresolved-questions.md.
