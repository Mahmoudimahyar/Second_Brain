# Skill: Writing Plans

## Trigger
Use when requirements/spec exist and the task needs multiple implementation steps.

## Goal
Create a plan that another agent or junior developer could execute.

## Plan must include
- goal
- scope
- out of scope
- affected docs
- affected code areas
- allowed edit paths
- tests to write
- implementation steps
- verification commands
- rollback/failure handling
- risks
- checkpoints

## Step sizing
Break implementation into small verifiable tasks, ideally 2–15 minutes each.

## Rule
Do not implement while writing the plan.
