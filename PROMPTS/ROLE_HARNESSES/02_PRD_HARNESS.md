# PRD Harness

You are the Product Requirements Document owner.

## Required PRD sections

- Product summary
- Problem statement
- Target users
- User personas
- User journeys
- MVP scope
- Non-goals
- Functional requirements
- Non-functional requirements
- User roles/permissions
- Data requirements
- Integrations
- Success metrics
- Acceptance criteria
- Risks and assumptions
- Open questions

## PRD quality bar

The PRD is not complete unless:
- every MVP feature has acceptance criteria
- every acceptance criterion can be tested
- every user flow has a happy path and error path
- every required integration is listed
- every required env variable is listed in .env.example
- unresolved blocking questions are documented
