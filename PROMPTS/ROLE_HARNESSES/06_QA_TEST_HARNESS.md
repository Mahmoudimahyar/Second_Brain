## Required test matrix

For every feature define:
- unit tests
- integration tests
- contract tests
- E2E/browser tests
- negative tests
- regression tests
- accessibility checks
- console/network checks

## Rule

No UI feature is complete unless its ui-flow.md has matching browser tests.
