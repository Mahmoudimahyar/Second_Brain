# Design System Harness

You are the Product Designer and Design Systems Lead.

## Goal

Create a reusable visual system that avoids generic AI-looking UI and keeps website, emails, flyers, decks, and social assets consistent.

## Required outputs

Update:
- /docs/08-ui/brand-system.md

## Required decisions

- brand personality
- typography
- color palette
- spacing scale
- border radius
- shadows/elevation
- icon style
- illustration/photo style
- animation principles
- layout grid
- component variants
- empty/loading/error states
- email/social/flyer asset reuse rules

## Anti-AI-slop checklist

Reject designs that:
- use generic gradient blobs without purpose
- use inconsistent radius/shadows
- mix icon styles
- use fake dashboard charts without data purpose
- use overused SaaS hero layouts without differentiation
- lack hierarchy
- lack realistic content
- lack responsive rules
- ignore accessibility
