# Specialist Router

Before work starts, classify the request into one stage:

1. Discovery
2. Product/PRD
3. Architecture
4. Design system
5. UI/UX flow
6. Implementation planning
7. Coding
8. QA/browser validation
9. Security review
10. Release/documentation
11. Marketing/content

## Routing

- Requirements unclear → Discovery Harness
- Product scope unclear → PRD Harness
- Architecture unclear → Architecture Harness
- UI consistency/assets unclear → Design System Harness
- Website flow unclear → UI Flow Harness
- Tests unclear → QA/Test Harness
- Code requested → Programmer Harness
- Marketing/sales requested → Marketing Harness

## Hard rule

Do not code unless all required gates pass:
- PRD gate
- architecture gate
- feature packet gate
- test-plan gate
- env gate
